# ✿ Bellezza del fiore

### An elegant, interactive web-based piano experience.

**Bellezza del fiore** is a browser-based virtual piano inspired by the dreamy underwater atmosphere of *Chainsaw Man – The Movie: Reze Arc*. It combines an interactive piano keyboard, expressive sound effects, and delicate flower animations into one musical experience.

---

## 🌸 Features

### 🎹 Virtual Piano
- Two independent piano keyboard rows.
- Dual Row, Upper Only, and Lower Only display modes.
- Full 88-key piano range (A0–C8).
- Adjustable keyboard range and key count.
- Computer keyboard controls.
- Mouse, touchscreen, and multi-touch support.
- Polyphonic playback for playing multiple notes simultaneously.

### 🎼 Instrument Presets
Choose between three piano sound profiles:
- **Concert Piano** – A balanced piano sound.
- **Acoustic** – A warmer, softer tone.
- **Bright** – A brighter, more pronounced sound.

### 🎛️ Audio Controls
- Adjustable master volume.
- Sustain functionality.
- Independent audio effects:
  - Distortion
  - Reverb
  - Echo
- Built-in metronome.
- Adjustable BPM (40–220).

### 🌷 Visual Effects
- Animated flowers appear when piano keys are pressed.
- Responsive key-press highlights.
- Underwater-inspired visual theme.
- Glass-like translucent control panels.
- Responsive layout for desktop, tablets, and mobile devices.

| 2 3 5 6 7 9 0 | Black keys |

### Lower Keyboard

| Key | Note control |
|---|---|
| Z X C V B N M , . / A | White keys |
| S D G H J L ; | Black keys |

**Additional control:**
- `Spacebar` – Toggle sustain while held.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/bellezza-del-fiore.git
```

### 2. Open the project folder

```bash
cd bellezza-del-fiore
```

### 3. Check the project structure

```text
bellezza-del-fiore/
│
├── index.html
├── bellezza_underwater_theme.webp
└── README.md
```

### 4. Run the application

Open `index.html` in a modern web browser.

No additional installation or build process is required.

---

## 🌐 Deployment

The project can be hosted using **GitHub Pages**.

1. Push the project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Navigate to **Pages**.
4. Select the deployment branch and root folder.
5. Save your settings.

Your piano application will be published through GitHub Pages.

## ⚙️ Requirements

- A modern browser (Chrome, Edge, Firefox, or Safari).
- Internet connection for loading Tone.js and piano samples.
- Audio permission enabled in the browser.
- Speakers or headphones for audio playback.
